# 🖌️ OpenBrush

OpenBrush is an open source Blender brush pack for texture painting.

## How to edit the brushes

Editing the brushpack can be done directly from blender, using the [asset library](https://docs.blender.org/manual/en/latest/sculpt_paint/brush/brush_management.html).

The alpha textures used for the brushes were generated using [Material Maker](https://github.com/RodZill4/material-maker), which is also open source and free to download.
